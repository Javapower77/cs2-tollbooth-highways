# AGENTS.MD

## Context

This project is a mod for Cities Skylines 2 in a context of a ECS environment with the DOTS architecture in Unity.

## Principal Objetive

Having specific type of Vehicles go through only a specific Tollbooth Road using a mapping to get the relationship between both of them.

## It must meet the following conditions

## Tollbooth road exclusive for specific vechile type

- For the logic of having specific vehicle type with a specific tollbooth road type take this in consideration
 -- If the tollbooth road is of type Private Transist, it will only allow passthrough cars, cars with trailer and motobikes.
 -- If the tollbooth road is of type Public Transport, it will only allow passthrough taxis and buses.
 -- If the tollbooth road is of type Heavy Transist, it will only allow passthrough delivery trucks.
 -- If the tollbooth road is of type Service Transist, it will only allow passthrough services transport like ambulance, police car, etc.

## Payment and Economy

- The tollbooth collect different amount of money from vehicles. The values can be modified from the settings of this mod.  
- There are two groups, one from manual and other for automatic tollbooth. Also is divided by Peak and Non Peak hours. Lastly, there are price for each type of vehicles.
Tollbooth road entities has a component called `TollBoothInsight` where records the money collect according to the mod setting mods, the type of vehicle, the type of tollbooth road and the time of the day/night.
- The following information if the data collected from the tollbooth:
  - **TotalVehiclesPassed**: Total number of vehicles that.
  - **TotalRevenue**: Total revenue generated by this tollbooth.
  - **PersonalCarCount**: Number of personal cars that have passed through.
  - **PersonalCarWithTrailerCount**: Number of personal cars with trailers that have passed through.
  - **TruckCount**: Number of trucks that have passed through.
  - **TruckWithTrailerCount**: Number of trucks with trailers that have passed through.
  - **BusCount**: Number of buses that have passed through.
  - **TaxiCount**: Number of taxis that have passed through.
  - **ParkMaintenanceCount**: Number of park maintenance vehicles that have passed through.
  - **RoadMaintenanceCount**: Number of road maintenance vehicles that have passed through.
  - **AmbulanceCount**: Number of ambulances that have passed through.
  - **EvacuatingTransportCount**: Number of evacuating transport vehicles that have passed through.
  - **FireEngineCount**: Number of fire engines that have passed through.
  - **GarbageTruckCount**: Number of garbage trucks that have passed through.
  - **HearseCount**: Number of hearses that have passed through.
  - **PoliceCarCount**: Number of police cars that have passed through.
  - **PostVanCount**: Number of post vans that have passed through.
  - **PrisonerTransportCount**: Number of prisoner transport vehicles that have passed through.
  - **MotorcycleCount**: Number of motorcycles that have passed through.
- The logic consist in monitor entities of type `Game.Vehicles.Car` passing through a tollbooth road identified with the component `TollRoadPrefabData` in the `Game.Net.Edge.m_End` (leaving the road) and perform the calculation of the amount of money depending in the previous explanation.
- The money will be added to the `Game.Economy.Resource.Money` of the game.

## Best Practices to follow
  
- By default all system should be in Burst-compatible code to follow the ECS best practices.
- System should inherit from `GameSystemBase` (not ISYSTEM).
- The systems should run in parallel threads in order to improve at best the performance.
- Always use `SystemAPI` when getting lookups or typehandles for a Jobs in Burst-compatible code.
- Use `BufferTypeHandle` instead of `BufferLookup` for buffered entities lookups.
- Use `ComponentTypeHandle` instead of `ComponentLookup` for not buffered component lookups.
- "**Update(ENTITY-QUERY)**" should be not necessary for lookups as it is handled internally.
- Use `ComponentTypeHandle` with `chunk.Has()` for component checks.
- Use `VehiclesUtil` class to check vehicles entities with tollbooth roads entities.
- Use `VehicleDebugLogger` to log what is the code doing for each vehicle.
- Register the system in `Mod.cs` to proper update the phases using updateSystem.
